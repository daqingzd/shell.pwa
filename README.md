# shell.pwa
shell.pwa is a project to implement console/shell app with pwaos runtime client API support.

# Branch c
a shell written in C, built with the pwaOS SDK.

# How to build
On Linux
1) Download pwaos_sdk from https://www.pwaos.net/usage.html
2) Set PWAOS_SDK_DIR environment variable
3) cmake .
4) make
